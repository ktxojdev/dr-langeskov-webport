# Dr. Langeskov, The Tiger, and The Terribly Cursed Emerald - Web Port

A full browser WebGL port of *Dr. Langeskov, The Tiger, and The Terribly Cursed Emerald* by Crows Crows Crows.

### Port Details
- **Engine**: Unity 5.6 WebGL (IL2CPP + Emscripten)
- **Rendering**: Forward Rendering with WebGL fallback shaders
- **Platform**: WebGL 2.0 / WebGL 1.0 with multipart chunk streaming
- **Audio**: Web Audio API with synchronized dialogue & sound effects
